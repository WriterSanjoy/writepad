◈ Google Drive Sync

A free Google OAuth Client ID is needed once — takes ~5 min.
How to get one ▾

1  Go to console.cloud.google.com
2  New project → any name (e.g. WritePad)
3  APIs & Services → Enable APIs → Google Drive API → Enable
4  Credentials → Create Credentials → OAuth client ID
5  Configure consent screen if prompted → External → save
6  Application type: Web application
7  Authorised JavaScript origins → Add:
    https://writersanjoy.github.io
8  Copy the Client ID → paste below
✓  No scope changes needed in Console — app uses only drive.file

pCloud Sync

Generate a free API token from pCloud — takes 30 seconds:

Step 1  Go to my.pcloud.com and log in
Step 2  Click your avatar → Settings → Security
Step 3  Scroll to "API Tokens" → click Generate
Step 4  Copy the token and paste it below
